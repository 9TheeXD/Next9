# คู่มือและวิธีการใช้งานแอปพลิเคชัน NextBreath (ฉบับสมบูรณ์)
แอปพลิเคชัน NextBreath เป็นแอปที่ออกแบบมาเพื่อช่วยให้ผู้ใช้เลิกบุหรี่ได้สำเร็จ โดยแบ่งผู้ใช้งานออกเป็น 2 บทบาทหลัก คือ **ผู้สูบ (Smoker)** และ **ผู้ติดตาม/ครอบครัว (Family)** ซึ่งทั้งสองบทบาทจะทำงานร่วมกันเพื่อเป้าหมายในการเลิกบุหรี่

---

## 🟢 1. สำหรับผู้สูบ (Smoker)

### 1.1 การเข้าสู่ระบบและแบบสอบถาม (Login & Survey)
- **การเลือกบทบาท:** เมื่อเปิดแอป ผู้ใช้จะเลือก "ฉันคือผู้สูบ"
- **การทำแบบสอบถาม:** ระบบจะบังคับให้ทำแบบสอบถามก่อนใช้งาน (อายุ, เพศ, อาชีพ, ชนิดบุหรี่, ความถี่, ช่วงเวลาที่อยากสูบ, ระยะเวลาที่สูบมา, เหตุผลที่อยากเลิก ฯลฯ)
- **การสร้างบัญชี:** แอปจะสร้างบัญชีให้โดยอัตโนมัติ (ผ่าน Display ID แบบสุ่ม 4 หลัก) ไม่ต้องใช้อีเมลหรือรหัสผ่าน บัญชีผูกกับเครื่องที่สร้างไว้ด้วยกุญแจลับในเครื่อง คนอื่นที่รู้รหัส 4 หลักจึงเข้าบัญชีแทนไม่ได้

### 1.2 หน้าหลักและการบันทึก (Home & Daily Tracker)
- **Level & XP:** มีระบบเลเวล (ระดับพลังใจ) แสดงความคืบหน้า สะสม XP จากการเล่นเกมและบันทึกพฤติกรรม
- **Daily Tracker:** แผงควบคุมหลักสำหรับบันทึกจำนวนบุหรี่ที่สูบในแต่ละวัน (เพิ่ม/ลดจำนวนได้)
- **สถิติรายวัน (Streak):** แสดงจำนวนวันที่ต่อเนื่อง (สตรีค), จำนวนมวน/พัฟที่ลดได้ และจำนวนเงินที่ประหยัดไปได้ (฿)
- **Gamification:** เมื่อบันทึกสำเร็จจะได้รับเหรียญตรา (Badges) และ XP มีหน้าต่างแจ้งเตือนแสดงความยินดี (Badge Celebration) และข้อความให้กำลังใจ (Daily Quote)
- **ปุ่ม Chat (มุมขวาล่าง):** เปิดหน้าต่างแชทเพื่อพูดคุยกับ AI หรือระบบให้คำปรึกษา

### 1.3 เมนูช่วยเหลือตอนอยากสูบ (SOS)
- **ปุ่ม "ฉันอยากสูบตอนนี้"** (มีทั้งในหน้า SOS และหน้าหลัก) พาผ่านความอยากทีละขั้น:
  1. ให้คะแนนความอยาก 1–10 และเลือกสิ่งกระตุ้น (เครียด หลังกินข้าว กาแฟ ฯลฯ)
  2. ดูภาพ "คลื่นความอยาก" ที่ขึ้นแล้วลดลงเอง แอปโชว์แผน "ถ้า…ฉันจะ…" ที่ผู้ใช้วางไว้สำหรับสิ่งกระตุ้นนั้น
  3. เลือกวิธีรับมือ: เล่นเกม 3 นาที, หายใจช้าๆ, ขยับร่างกาย 4 นาที, อ่านเหตุผลที่อยากเลิก, หรือคุยกับคน (1600, คนสนิท, ครอบครัว, ชุมชน)
  4. ให้คะแนนความอยากอีกครั้ง แอปแสดงว่าลดลงเท่าไหร่ และได้ XP
- **เกมเบี่ยงความสนใจ** (กราฟิกวาดด้วยโค้ด เล่นออฟไลน์ได้ มีเสียงประกอบ):
  - ต่อบล็อกดวงดาว: เกมเรียงบล็อก งานวิจัยพบว่าเล่นเกมแบบนี้ 3 นาทีช่วยลดความอยาก
  - สวนอัญมณี: เกมเรียงอัญมณี 3 เม็ด รอบละ 3 นาที ไม่มีแพ้
  - เส้นทางดวงดาว: จำลำดับดาวแล้วแตะตาม ฝึกความจำ
  - โคมลอยลมหายใจ: หายใจเข้า 4 วินาที ออก 6 วินาที ทุกลมหายใจปล่อยโคมขึ้นฟ้า
- **เครื่องมืออื่น:** ขยับร่างกาย 4 นาที (6 ท่า), ข้อความเสียงให้กำลังใจ, บันทึกความอยาก, กิจกรรมทดแทน, และ **"เผลอสูบไป"** ที่ช่วยหาสาเหตุและวางแผนรับมือครั้งหน้าโดยไม่ต้องเริ่มนับใหม่จากศูนย์
- **คุยกับคน:** สายเลิกบุหรี่ 1600, คนสนิท (เบอร์ที่ตั้งไว้), แจ้งครอบครัว, สายด่วนสุขภาพจิต 1323

### 1.3.1 แผนของฉัน (แท็บ "แผนเลิก" → "แผนของฉัน")
- สรุปจากประวัติความอยาก: จำนวนครั้งที่ผ่านไปได้, ความอยากลดลงเฉลี่ย, สิ่งกระตุ้นบ่อย, ช่วงเวลาเสี่ยง, วิธีที่ได้ผลที่สุด
- เหตุผลที่อยากเลิก (แสดงให้อ่านตอนอยากสูบ) และแผน "ถ้า…ฉันจะ…"
- อาการถอนนิโคตินแต่ละช่วง และตัวช่วยที่ได้ผลจริง: 1600, ยาช่วยเลิก (นิโคตินทดแทน ไซทิซีน วาเรนิคลีน) ผ่านเภสัชกรหรือแพทย์
- ข้อมูลส่วนนี้เก็บไว้ในเครื่องของผู้ใช้ ส่วนเหตุการณ์ (ความอยากก่อน-หลัง การเล่นเกม การเผลอสูบ) ส่งเข้า action log ให้ admin ดูได้

### 1.4 เมนูสุขภาพและการเงิน (Health)
- แสดงเงินที่ประหยัดได้ทั้งหมด และเปรียบเทียบเป็นของรางวัล (เช่น ซื้อกาแฟได้กี่แก้ว, ดูหนังได้กี่เรื่อง)
- **ไทม์ไลน์การฟื้นฟู:** แสดงความก้าวหน้าของสุขภาพร่างกายตามระยะเวลาที่เลิกสูบ (ปลดล็อกไปทีละขั้น)

### 1.5 แผนเลิกบุหรี่ (Knowledge / Plan)
- บทความให้ความรู้ (ความจริงเกี่ยวกับบุหรี่, กลอุบายของสมอง, เรื่องราวแรงบันดาลใจ)
- ขั้นตอนการเตรียมตัวเลิกบุหรี่ (Practical Steps)
- แบบทดสอบ (Quiz) เพื่อประเมินความรู้และรับ XP เพิ่มเติม

### 1.6 โปรไฟล์และการตั้งค่า (Profile)
- แสดง ID รหัสประจำตัว 4 หลัก
- ตั้งค่าเป้าหมาย: จำนวนบุหรี่ต่อวัน, ราคาต่อซอง, เบอร์โทรคนสนิท (Emergency Contact)
- **QR Code ประจำตัว:** สำหรับให้ "ผู้ติดตาม" สแกนเพื่อเชื่อมต่อบัญชีเข้าด้วยกัน
- ดูสรุปความสำเร็จ เหรียญตรา (Badges) และสถิติสูงสุด

## 🟣 2. สำหรับผู้ติดตามหรือครอบครัว (Family / Follower)

### 2.1 การเข้าสู่ระบบและการเชื่อมต่อ (Login & Connect)
- **การเลือกบทบาท:** เลือก "ฉันต้องการติดตามผู้สูบ"
- **การเชื่อมต่อ:** ต้องกรอกรหัส 4 หลักของผู้สูบ (ดูได้จากหน้าโปรไฟล์ของผู้สูบ) หรือใช้การสแกน QR Code เพื่อเชื่อมโยงบัญชี
- **แบบสอบถามผู้ติดตาม:** ตอบคำถามเกี่ยวกับความสัมพันธ์, ความกังวล, และวิธีที่อยากสนับสนุนผู้สูบ (รวมถึงการตั้งเป้าหมายให้รางวัล)

### 2.2 หน้าจอสรุปข้อมูลผู้สูบ (Family Dashboard)
- แสดงสถานะและสถิติของผู้สูบที่ติดตามอยู่ (สตรีคปัจจุบัน, จำนวนที่ลดได้, เงินที่ประหยัดได้)
- **ปุ่มส่งกำลังใจ (Send Cheers):** สามารถกดส่งข้อความให้กำลังใจ หรือส่งอิโมจิไปให้ผู้สูบได้โดยตรง (ผู้สูบจะเห็นเป็น Popup แจ้งเตือน)
- มีปุ่มแจ้งเตือน SOS เมื่อผู้สูบต้องการความช่วยเหลือ

### 2.3 เมนูประวัติ (History)
- ดูประวัติการบันทึกการสูบย้อนหลังของผู้สูบแบบ Timeline และกราฟแนวโน้ม (Trend)
- ดูสรุปภาพรวมว่าผู้สูบทำกิจกรรมอะไรไปบ้าง (อ่านบทความ, เล่นเกม, ทำแบบทดสอบ)

### 2.4 เมนูคำแนะนำ (Guidance)
- ข้อแนะนำวิธีดูแลจิตใจและให้ความช่วยเหลือผู้ที่กำลังเลิกบุหรี่อย่างถูกต้อง (เช่น การให้กำลังใจไม่จับผิด, การรับฟัง, ชวนทำกิจกรรมเบี่ยงเบนความสนใจ)

### 2.5 เกมผ่อนคลาย (Games)
- ผู้ติดตามเล่นเกมชุดเดียวกับผู้สูบได้ (ต่อบล็อก, อัญมณี, ดวงดาว, โคมลอยลมหายใจ) เพื่อรู้จักเครื่องมือที่ผู้สูบใช้ ชวนกันเล่นตอนผู้สูบอยาก หรือใช้พักใจเอง

## 🔗 3. ระบบการเชื่อมต่อ (QR Code & PWA)
- แพลตฟอร์มรองรับการใช้งานแบบ PWA (Progressive Web App) สามารถติดตั้งลงบนหน้าจอโฮม (Add to Home Screen) ได้ทั้ง iOS และ Android
- **Flow การจับคู่:** 
  1. ผู้สูบเปิดหน้าโปรไฟล์ โชว์ QR Code หรือรหัส 4 หลัก
  2. ผู้ติดตามใช้มือถือสแกน QR Code หรือกรอกรหัส 4 หลักในหน้าสมัครสมาชิก
  3. ระบบจะซิงค์ข้อมูลให้ผู้ติดตามสามารถดูสถิติและส่งกำลังใจให้ผู้สูบได้ทันที
