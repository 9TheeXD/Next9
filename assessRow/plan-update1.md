# Plan Update: Morning Assembly Disciplinary Tracking System
**File:** `update_plan.md`

## Update Log: Trend Graph Detail View Modifications
This document outlines the specific changes applied to the original plan.

**1. Room-Level Trend Graphs (กราฟรายห้อง)**
* When clicking a grade header in the Trend Graph section to view details in a popup, the system must now display **individual trend line graphs for each specific room** within that grade, rather than an aggregate view.

**2. Dynamic Header with Timeframe Average (หัวข้อแสดงค่าเฉลี่ยตามช่วงเวลา)**
* The header inside the detail popup must dynamically display the average score and text rating for that grade based on the selected timeframe.
* **Format Example:** If a 2-month period is selected and the average score is 3, the header must show `"ม.2 (เฉลี่ย 3 พอใช้) >"`.
